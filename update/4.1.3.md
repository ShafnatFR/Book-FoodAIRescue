**4.1.3 Langkah Instalasi dan Konfigurasi Sistem**
Untuk menginstal dan menjalankan platform FoodAI Rescue secara lokal (*localhost*), langkah-langkah berikut dapat diikuti:

1. Unduh (*clone*) *source code* aplikasi dari repositori GitHub dan buka proyek tersebut menggunakan IDE (misalnya Visual Studio Code).
2. Siapkan dan aktifkan layanan basis data MySQL melalui panel kontrol XAMPP atau Laragon.
3. Jalankan server *backend* (arahkan terminal ke folder `server` lalu ketik `npm run dev`) dan berikan izin saat muncul peringatan untuk melakukan migrasi *database* secara otomatis.
4. Lakukan konfigurasi akun utama melalui terminal dengan memasukkan *email* dan *password* untuk *Super Admin*, lalu \textit{scan} QR Code untuk menautkan layanan *gateway* WhatsApp.
5. Jalankan server *frontend* (buka terminal baru pada direktori utama lalu ketik `npm run dev`).
6. Akses dan jalankan sistem melalui peramban (*web browser*) pada alamat http://localhost:3000/.
